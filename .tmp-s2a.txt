## 2. MzansiConnect helper chatbot

A chat icon in the bottom-right corner of every page opens the **MzansiConnect helper**.

- Matches questions against **20+ topics**: deals, payments, refunds, delivery, codes, exchange, transport, cart, verification, funding, fees, training and more.
- Answers greetings in English, isiZulu, Sesotho and isiXhosa.
- Says plainly when a feature doesn't exist yet. It never makes one up.
- Shows 7 quick-question chips the first time it opens.
- Answers come with buttons that jump to the right page.
- Uses Claude for more natural answers when `ANTHROPIC_API_KEY` is set. Without the key, the built-in rules answer everything.
- Works offline, in local data mode and in the prototype.

| File | What it does |
|---|---|
| `lib/helpbot.ts` | Topics, keywords, answers |
| `components/HelpBot.tsx` | The chat window |
| `components/AppShell.tsx` | Shows the chatbot for every role |
| `app/api/ai/chat/route.ts` | Optional Claude answers |

To add a new topic, add one entry to the `INTENTS` list in `lib/helpbot.ts`:

```ts
{
  id: "my-intent",
  keywords: ["keyword1", "keyword2"],
  answer: "Your answer here.",
  buttons: [{ label: "Go there →", href: "/owner/somewhere" }],
}
```
